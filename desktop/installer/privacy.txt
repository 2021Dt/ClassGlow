ClassGlow 班级看板 · 安装与隐私说明

本程序仅安装到当前 Windows 用户：
  程序：您选择的安装目录（默认 %LOCALAPPDATA%\Programs\ClassGlow）
  业务数据：%LOCALAPPDATA%\ClassroomBoard
  当前用户的开始菜单及“已安装的应用”卸载入口；可选创建桌面快捷方式。
不申请管理员权限，不添加系统服务、计划任务、驱动或防火墙规则。

安装完成不会自动启动程序。首次手动运行会显示完整隐私说明；
同意前不联网、不创建业务数据、不改壁纸。壁纸展示和开机启动默认关闭。
如以后主动开启开机启动，仅添加当前用户 Run 键下的 ClassroomBoard 值。

程序只连接您配置的服务器，默认 teacher.dgplus.vip。
配对发送计算机名称；绑定后发送设备标识、版本、同步/展示状态及控制回执。
本班老师刷新时，会回传本程序已设置的看板缩略图、版本和时间，供本班成员
及系统管理员查看；每台设备仅保留最近一张，备份可能包含当时的画面。
服务端会收到网络连接的 IP 地址。客户端不截取桌面或其他窗口，不收集键盘输入、
浏览历史、摄像头、麦克风或个人文档，也没有第三方统计或广告。
设备凭证和业务快照用当前用户 DPAPI 加密；生成的壁纸是明文 PNG。
玻璃材质使用本机已有的 Microsoft Edge WebView2 运行时绘制离线资源，
渲染网页不访问互联网，不接收账号凭证或作业正文。未安装运行时则使用兼容材质。
材质 PNG、校验文件和临时 material-webview 缓存仅放在上述业务数据目录，
随本程序卸载清理；不会安装或卸载系统共享的 WebView2 运行时。
异常日志有大小上限，不包含教学正文或凭证。首次界面打开失败时也可能记录
本机启动诊断：时间、应用/系统/运行时版本、绘制方式、异常类型和应用方法名；
不记录异常正文、本机文件路径或账号，不自动上传，卸载时一并清理。

卸载入口：安装目录内的 Uninstall.exe、客户端“卸载软件”、
Windows“已安装的应用”、开始菜单或客户端托盘。
卸载将停止同步，恢复本程序仍占用的壁纸，再清除本程序文件、启动项、
快捷方式、本机凭证、缓存、同意记录和日志。
您自行更换的壁纸和放入目录的其他文件会保留；不会递归清空用户目录。
恢复壁纸失败时会停止卸载并保留恢复记录。原壁纸已丢失时尝试恢复系统纯色。
联网时撤销本设备或待确认配对，并清除服务器当前回传画面；离线卸载需由教师在网页撤销原设备。
服务器班级、教学内容、审计和备份仍由学校/管理员管理，不随本机卸载删除。
Windows 自己维护的系统缓存、日志及您下载的安装包不会被擅自清除。

这是未签名的测试版，当前不自动替换或升级程序。
完整说明可在安装后从“隐私与本机数据”随时查看。
