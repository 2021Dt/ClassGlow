# Windows 隐私与卸载

适用版本：0.4.10，隐私说明修订号 `2026-11-04.2`。本版补充离线玻璃材质、WebView2 与缓存范围，升级后需重新阅读并同意说明；不自动代替用户同意。WPF UI、WebView2 SDK 和离线网页依赖的许可文件包含在卸载清单中。本文不替代学校对服务器数据的管理制度。

## 首次运行与数据

安装完成不会自动运行。首次手动打开按“隐私说明、连接班级、展示设置”分三步进行，同意框默认未选中；拒绝则退出。获得同意前不联网、不创建业务数据、不启用启动项、不修改壁纸。升级后若说明修订，开机启动会安静退出，等待用户手动打开并重新确认。

只连接配置的服务器，默认 `https://teacher.dgplus.vip/api/`。首次配对发送计算机名称；绑定后发送设备标识、客户端版本、同步/展示状态、页码、暂停状态和控制回执。服务器能看到连接 IP。客户端读取班级正式内容、课表、主题及背景图，不上传当前桌面，不收集键盘输入、浏览历史、摄像头、麦克风或个人文档，没有广告或第三方统计。

| 位置 | 用途 |
| --- | --- |
| 用户选择的安装文件夹，默认 `%LOCALAPPDATA%\Programs\ClassGlow` | 程序、运行时、隐私说明及卸载器 |
| 当前用户桌面 `ClassGlow 班级看板.lnk` | 安装时可取消的桌面快捷方式 |
| `%LOCALAPPDATA%\ClassroomBoard` | DPAPI 加密的 `state.bin`；明文桌面 PNG；`privacy.json`；有大小上限的日志 |
| 同一数据目录下的 `glass-material.png`、`.key` 与 `material-webview` | 当前材质缓存、校验值和本程序专用 WebView2 临时数据；卸载清理 |
| `%APPDATA%\Microsoft\Windows\Start Menu\Programs\ClassGlow` | 两个开始菜单快捷方式 |
| `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\ClassroomBoard` | 当前用户卸载入口 |
| `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下 `ClassroomBoard` | 仅在用户勾选自动启动并保存设置后添加 |

日志单份上限约 128 KiB，并保留一份滚动旧日志。启动或界面失败时，`startup.log` 记录时间、程序/Windows/运行时版本、绘制模式、异常类型/错误码及应用内部的方法名；首次隐私页打开失败也可能生成该记录。不记录异常正文、源码路径、账号、凭证或教学内容，不自动上传。其他日志仍仅记录异常类型与时间。不会安装系统服务、驱动或计划任务，也不会修改防火墙。设备凭证和班级快照使用当前用户 DPAPI；生成的 PNG 包含教学内容，是明文，不能当作已加密文件。

班级成员点击“刷新画面”后，客户端最多回传 1280 像素、400 KB 的 JPEG，来源是已经成功设置的本程序看板 PNG。不会截取整个桌面、课件、其他窗口或原壁纸。仅当前班级成员和系统管理员经过登录可读；每台设备在 `device_displays` 中保留最近一份，更新时覆盖。暂停、关闭展示或本机更换壁纸会回传对应状态，不上传其他图片。图片包含看板上的教学内容，数据库备份可能包含当时的图片。解绑、归档或联网卸载清除当前回传，历史备份需管理员单独删除。

## 卸载步骤和范围

玻璃底图通过本机已有的 Microsoft Edge WebView2 运行时加载安装目录 `Renderer` 内的离线资源。网页仅收到布局外观和图片，不收到设备凭证或作业正文；网络请求限制为本机虚拟资源域名。绘制完成关闭浏览器控制器，不常驻网页。临时缓存可能在运行时释放文件锁后才清除，退出/卸载仍按固定专用子目录处理。不会安装或卸载系统共享 WebView2；运行时缺失或绘制失败自动使用原生兼容材质。

从客户端“卸载软件”、安装目录 `Uninstall.exe`、Windows“已安装的应用”、开始菜单“卸载班级看板”或托盘卸载入口发起。托盘“隐私与本机数据”也可以撤回同意并卸载。

1. 停止正在运行的客户端和同步请求。
2. 恢复仍使用本程序图片的屏幕；老师后来手动更换的壁纸保持不变。原图片已丢失时尝试恢复系统纯色，恢复失败则停止卸载并保留恢复记录。
3. 在线撤销自己的设备或待确认配对，取消本设备未执行命令。不会撤销其他设备或删除教学内容。
4. 删除已知程序文件、本机状态、凭证、壁纸缓存、同意记录、日志、自己的启动项、快捷方式和卸载登记。兼容清理旧版两个明确命名的临时日志。

网络不可达时会询问是否继续本机卸载。选择继续后，老师需在网页“教室电脑”撤销原设备；静默卸载遇到此情况返回失败，保留卸载入口。文件被占用时可关闭占用程序后重试，不会自动重启电脑。

清理依据本产品文件清单，不递归清空用户目录。老师另放的文件和子目录会保留，因此目录非空时目录本身也会保留。服务器班级、教学内容、审计及备份由学校管理员管理，不随客户端卸载删除。Windows 自身的事件日志、缩略图等系统缓存，以及其他目录里的下载包，由系统或用户管理，不为追求“无痕”修改系统记录。

## 从旧便携版升级

先退出旧版，再安装当前版本。新版沿用当前用户的 `ClassroomBoard` 数据目录；尚未同意当前隐私说明的用户需阅读并同意。卸载新版会清理共享的本产品业务数据和启动项。

旧 ZIP 和自行解压到其他位置的程序副本不会被搜索或擅自删除；核对后由用户删除旧副本。不要把个人文档和其他程序一起删除。安装器不能替另一个 Windows 用户清理其数据；每个使用过的 Windows 账号应分别卸载。

## 验证边界

0.4.5 已用独立验证包在 Windows 11 实际安装到一个尚不存在、包含中文和空格的文件夹，确认说明正常、桌面快捷方式有效、卸载器和卸载登记存在。执行卸载后，程序、快捷方式和卸载登记清除，另放的测试文件保留。另用实际编译的客户端在进程内模拟失效代理，成功访问正式服务器生成并撤销待确认配对；未更改系统代理、真实壁纸或启动项。

0.2.0 的独立验证包另检查了拒绝同意、首次同意、默认设置、运行中卸载、启动项与卸载登记清除、快捷方式清除，以及自放文件保留。另有六项隔离的壁纸恢复/文件清理检查及一个后端自撤销流程。验证未更改当前电脑的真实壁纸；学校多屏、原壁纸恢复与连续运行仍需现场验收。

## 关闭与退出

同意首次隐私说明后，主窗口点击关闭或最小化会隐藏并从任务栏移除，托盘仍在，已授权的同步与展示继续运行。点击托盘图标或右键选择“打开班级看板”可恢复窗口；重复打开程序快捷方式也会请求显示已有窗口。完全结束请右键托盘选择“退出并恢复原壁纸”。未同意的首次隐私页仍可直接退出，不会启动后台同步。
